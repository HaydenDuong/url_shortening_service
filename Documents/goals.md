# Project Goals

## Goal

Build a production-inspired URL shortening service while learning:

- ASP.NET Core Web API
- PostgreSQL
- Entity Framework Core
- Redis
- RabbitMQ
- Docker
- Concurrency concepts
- Distributed systems fundamentals

The goal is not to clone Bitly, but to use a small backend service to explore these concepts incrementally.

## Learning Approach

For each phase:

1. Understand the problem first.
2. Identify relevant trade-offs.
3. Implement the simplest working solution.
4. Review limitations and failure modes.
5. Improve the design only when the current limitation justifies it.
